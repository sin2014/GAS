# UE Ring Semantic Exporter

UE Ring 是面向 Unreal Engine 5.8 项目的资产语义导出插件。它在 Unreal Editor 或 Editor Commandlet 中将二进制 `.uasset` / `.umap` 转换为稳定、可 diff、可索引的 USEM JSON。导出完成后，AI 和其他工具只需要读取 `.uesem/` 与关联源码，不需要启动 Unreal Editor，也不需要直接解析二进制资产。

当前版本：`0.20.1`，USEM schema：`2.9.0`，semantic revision：`44`。

P0-P3 已完成。下一阶段的设计审计、目标合同、分期顺序与 Lyra 验收门槛见
[`docs/P4_DESIGN_AUDIT_AND_ROADMAP.md`](docs/P4_DESIGN_AUDIT_AND_ROADMAP.md)。

## 0.20.1 Editor-truth fidelity

Lyra editor/MCP comparison scope, fixed gaps, tool boundaries, and final evidence are recorded in [`docs/LYRA_EDITOR_TRUTH_ACCEPTANCE_0.20.1.md`](docs/LYRA_EDITOR_TRUTH_ACCEPTANCE_0.20.1.md).

- Blueprint custom events preserve authoritative names, RPC/function flags, editor/deprecation metadata, and override state.
- Pins preserve split-pin parent/child identity, persistent GUIDs, orphan/connectability state, and authored versus autogenerated defaults; nested graphs expose their parent graph path.
- Changed inherited class defaults retain reachable instanced UObject graphs and their reflected properties without scanning unrelated CDO objects.
- World Partition external actors remain consolidated into the owning World sidecar, with complete descriptors and forced-load Actor/Component property semantics plus explicit failure accounting.
- Control Rig exports the authored hierarchy, parent relationships, initial/current local transforms, and reflected control settings in addition to its graph mirror.
- Object redirectors are explicitly excluded, preventing stale redirector sidecars from surviving a full export.
- Widget Blueprints preserve every authored `UWidgetAnimation` and its reachable MovieScene track, section, channel, and key data as a deterministic owned-object graph.

## 0.19.1 Scalable incremental derived indexes

- Changed contributors are built as package-local graph fragments and applied transactionally to SQLite; incremental updates no longer parse the 78 MB project graph JSON.
- The canonical project graph JSON is streamed from ordered SQLite cursors directly to an atomic UTF-8 output file, avoiding a full in-memory JSON object tree while remaining byte-identical to a full rebuild.
- SQLite user version 6 preserves Blueprint graph and raw node scopes, resolves membership-changing contributors directly from the database, and rejects dangling graph endpoints before commit.
- C++ reflection reverse links remove and merge only dirty-package `cppLinks`; Blueprint migration candidates remove and recompute only dirty packages. Missing or incompatible state safely falls back to a full rebuild.
- No-change, changed-contributor, and deleted-sidecar automation compares incremental project indexes, dependency graphs, unified graphs, C++ reflection, and migration reports byte for byte against full rebuilds.
- On Lyra, a changed graph contribution now completes in about 1.7 seconds, including about 1.0 second to stream the canonical 78 MB graph, while a no-change package remains about 0.67 seconds.

## 0.19.0 Incremental project indexing

- 单资产、选择集、文件夹、依赖导出、保存、删除、重命名和 MCP 导出改为包级增量更新项目索引，不再无条件重建整个 JSON/统一图/SQLite 索引。
- 项目索引为每个资产记录 `semanticSectionBytes`，增量更新时可精确重算全局区块统计，无需重新解析全部 sidecar。
- Project Graph 1.1 的每条边记录 `contributorPackage`；真实语义变化只替换对应贡献者的节点和边，并清理孤立非资产节点。依赖或成员关系变化会扩展到必要的引用者。
- SQLite user version 5 在单个 `BEGIN IMMEDIATE` 事务内删除并 upsert 受影响的资产、标签、领域、依赖和统一图贡献，完成后执行端点闭合与快速完整性检查。
- `semanticHash` 未变化时跳过统一图读取和写入；Lyra 单资产无变化索引从约 4.4 秒降至 0.6 秒，完整 Commandlet 约 1.0 秒。
- 自动保存去重；重命名旧路径只触发索引失效，删除会撤销尚未执行的自动导出，避免异步读取已经消失的 `.uasset`。
- 全量导出删除孤儿语义、摘要和图后会递归修剪空目录，不保留自动化或旧资产的目录外壳。
- 自动化同时验证无变化与真实变化的增量产物均和全量重建逐字节一致。Lyra revision 37 的性能、体积与完整验收见 `docs/LYRA_SCALE_ACCEPTANCE_0.19.0.md`。

## 0.17.1 DataAsset executable reconstruction

- `UPrimaryDataAsset::AssetBundleData` is omitted because Unreal regenerates it during save; PrimaryAssetLabel authored rules remain, while large location-dependent bundle caches no longer inflate semantics or reconstruction blockers.
- `FUtf8String` and `FAnsiString` reflection properties are serialized and reconstructed as lossless JSON strings.
- Lyra revision 31 acceptance, readiness, size, and exact DataAsset round trips are documented in `docs/LYRA_SCALE_ACCEPTANCE_0.17.1.md`.

- DataAsset 新增 `data-asset-properties-v1` 语义表示和 `editor.dataAsset.create`、`editor.dataAsset.applyProperties` 白名单 opcode；生成器通过运行时反射恢复真实资产类，不需要生成代码直接依赖项目模块类型。
- 支持 Enum、数值、Bool、String、Name、FText、软/硬对象引用、固定数组、Array、Set、Map 和嵌套 Struct；生成资产仍只能写入 `/Game/UERingGenerated/...`，并要求对象名与源资产一致以保持 Primary Asset Id。
- 同包 instanced/owned UObject、脱敏值、超过 JSON 精确整数范围的数值、未知属性类和无法恢复的本地化显示文本会产生明确 blocker，不会把部分数据误报为 `exact`。
- 修复 `GameplayTagQuery.QueryTokenStream` 与 `TokenStreamVersion` 被通用 `*Token*` 隐私规则误脱敏的问题；真正的认证 Token 仍继续过滤。

## 0.13.0 GAS, Experience, and GameFeature semantics

GAS, Lyra Experience, and GameFeature projections now use role-specific v2 representations.
Selected typed property values are grouped by semantic purpose instead of repeating reflection
property wrappers. GameplayEffect duration, period, modifiers, executions, stacking, immunity,
requirements, cues, and execution policy are retained. GameFeature owned actions expose compact
configuration for input mappings, components, registries, gameplay cues, and asset scanning.

## 0.12.0 MetaSound semantic graph

registry caches.

## 0.6.1 验收加固

- MCP 查询只接受合法 `/Game` 长包名，并以最终 MCP 工具响应的 UTF-8 序列化大小执行 `max_bytes` 预算。
- Bundle 对规范化后的目标路径执行根目录 containment；`cppLinks` 只允许复制批准源码根中的 C/C++ 文件。
- `UERingExport` 强制显式且互斥地选择 `-All` 或 `-Package`；非法、零匹配和缺失 Scope 均返回非零。

- precommit 双向检查资产和 Sidecar；重命名 tombstone 分别保存旧、新身份。
- 领域摘要增加 DomainGraph、Sequencer 和 Paper2D 的高辨识度指标。
- 移除未实现的 `MaxConcurrentExports`，避免把 UObject 遍历错误并发化；后续性能工作必须先拆分线程安全阶段。
- 移除 `bExportOnBlueprintCompile`。编译但未保存的内存态不会伪装成与磁盘 `.uasset` SHA-256 对应的 Sidecar；保存资产仍会自动导出。

- PaperTileSet 使用 `sparse-default-v1` 专用语义格式，仅记录有效 metadata 覆盖项，避免展开数万个默认槽位。
- DataTable 提供 internal/authored/display 字段名映射；继承 Widget 声明提供可选原因；Timeline 缺失曲线生成结构化诊断。
- 超长 `exportText` 会标记为 omitted，完整类型化 `value` 仍保留。
- 离线索引校验默认核对 sidecar JSON、交叉字段和 SHA-256；`--verify-source-hashes` 可进一步核对源资产。

## 资产与工作流能力

- Blueprint：从 Generated Class CDO 读取类型化变量默认值，递归导出接口图、Collapsed/SubGraph、按 Schema 分类的动画图、Timeline 曲线、稳定 Node/Pin 连线、Delegate 等节点的结构化成员引用、组件挂接树和组件模板覆盖。
- Widget Blueprint：完整 Blueprint 语义、Widget 顺序、父 Widget Blueprint 树和原生父类 `BindWidget` 声明、`bIsVariable`、RenderTransform、类型化 Slot/样式属性、命名 Slot 和属性绑定。原生绑定使用 `declarationOnly=true`，不会伪造运行时 Widget 实例。
- Map / World：World Partition 与 External Actors 状态、Streaming Level、可保存的 Persistent Level Actor GUID、类、Label、Folder、Transform、Tag，以及相对 Archetype 变化的 Actor/Component 实例属性、组件挂接和相对 Transform。Transient 编辑器/运行时 Actor 不进入 `actors`；`actorScope`、槽位数和跳过计数明确记录导出口径。
- DataAsset / PrimaryDataAsset：Primary Asset Id、owned UObject 图与排序后的类型化反射属性，支持递归容器、Struct、Instanced Struct、Property Bag、Optional、空 Delegate、Enum、FText、对象引用和隐私字段过滤。
- DataTable / CurveTable：RowStruct、排序后的类型化行字段和兼容 `exportText`，以及 Simple/Rich Curve Key。
- Paper2D：PaperTileSet 稀疏 metadata 与 PaperTileMap 可还原的分层单元格布局。
- LevelSequence：绑定、轨道、Section、通道索引、关键帧时间与类型化通道值。
- AnimBlueprint：完整 Blueprint 图语义及目标骨架、预览网格等动画属性。
- BehaviorTree / Blackboard / Material / Niagara / PCG：根资产属性、持久化 owned object、类型直方图和内部引用边。
- 反射兜底：未命中专用导出器的项目资产仍生成 `ReflectionFallback` sidecar，并明确标记语义能力限制。
- 通用依赖：hard、soft、management、referencers。
- 确定性输出：SHA-256 源哈希、导出器版本失效、稳定排序、原子替换、未变化跳过、中英 Markdown 摘要、图表和语义 diff。
- 编辑器操作：资产右键导出、带直接硬依赖导出、文件夹递归导出、AI Bundle、Tools 状态面板和 Project Settings 配置。
- 生命周期同步：保存后自动导出，删除后清理或保留 tombstone，重命名/移动后同步 sidecar；队列具有去重和防抖。
- 离线索引：项目 JSON/SQLite 资产索引、依赖图、C++ 反射索引、源码清单和 Blueprint 到 C++ 的反向引用。
- AI Bundle：Asset/Folder/Module/Primary Asset Type 范围，主资产优先的字节预算、直接依赖语义、关联 `.h/.cpp`、C++ 索引、依赖图、脱敏项目配置、manifest、上下文计划和中英分析提示。
- CI：`UERingExport` 与 `UERingValidate` Commandlet；验证 missing、stale、orphan 和无效 JSON。
- 错误追踪：批量任务单项失败不中断，详细失败追加到 `.uesem/logs/export-errors.jsonl`。

## 官方 MCP 与导出器 SDK

启用 UE 5.8 官方 MCP Server 后，插件自动向同一个 `ModelContextProtocol` 模块注册：

- `ue_ring_get_semantic`：按合法 `/Game/...` 包名查询已有 sidecar；`max_bytes` 限制最终结构化 MCP 工具响应的序列化字节数。
- `ue_ring_export_asset`：导出指定资产并可刷新项目索引。
- `ue_ring_validate_semantics`：返回 missing、stale、orphan、invalid 统计和消息。

项目自定义插件可包含 `UERingExporterRegistry.h` 和 `IUERingAssetExporter.h`，通过 `FUERingExporterRegistry::Register` 注册 `TUniquePtr<IUERingAssetExporter>`。保存返回的 `FUERingExporterHandle`，在模块关闭前调用 `Unregister`；优先级高的自定义导出器会先于内置或反射兜底导出器匹配。`UERingBundleBuilder.h` 同样属于 Public SDK，可构造 `FUERingBundleRequest` 调用四种 Bundle Scope。

## Commandlet

导出全项目：

```powershell
<UE_ROOT>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe <PROJECT>.uproject `
  -run=UERingExport -All -Unattended -NullRHI -NoSound -NoP4
```

导出单个包并创建离线 Bundle：

```powershell
<UE_ROOT>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe <PROJECT>.uproject `
  -run=UERingExport -Package=/Game/Blueprints/BP_Door `
  -Bundle=/Game/Blueprints/BP_Door -Unattended -NullRHI -NoSound -NoP4
```

创建 Module 集合 Bundle；`BundleScope` 还支持 `Asset`、`Folder` 和 `PrimaryAssetType`：

```powershell
<UE_ROOT>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe <PROJECT>.uproject `
  -run=UERingExport -All -BundleScope=Module -BundleValue=MyGame `
  -Unattended -NullRHI -NoSound -NoP4
```

`UERingExport` 必须显式且只能选择一个导出 Scope：`-All` 或 `-Package=/Game/...`。不存在、非法或不受支持的单包请求会返回非零；缺少 Scope 不会退化成全项目导出。

## Material Logic 语义

0.14.0 的默认 `logic` profile 为 Material、Material Function、Material Instance 和
Material Parameter Collection 输出专用语义，不再使用通用 owned-object graph：

- Material / Function 保存稳定表达式节点、未连接输入默认值、函数接口和带端口的连接；
- 连接明确记录源输出索引/名称、通道 Mask、目标节点和目标输入；
- Material Instance 只保存父级与本地参数、静态参数和材质属性覆盖，不复制父材质图；
- MPC 保存 Scalar / Vector 参数名、GUID 和默认值；
- 编辑器坐标、预览 UI、缩略图、Shader/Streaming 缓存等非逻辑内容通过 `omissions` 明确标记；
- 统一项目图和 SQLite 可查询 `materialNode`、`containsMaterialNode`、
  `feedsExpressionInput` 与 `feedsMaterialInput`。

Lyra 0.14.0 全量验收覆盖 535 个材质相关资产，材质语义从约 35.65 MB 降至
约 10.50 MB，所有 9,717 条材质连接均无悬空端点。详细数据见
`docs/LYRA_SCALE_ACCEPTANCE_0.14.0.md`。

## 提交前检查

Git / Git LFS 仓库在项目根目录运行以下命令即可检查已暂存变更；非零退出码会阻止提交：

```powershell
python <PLUGIN_ROOT>\tools\usem_precommit.py --project-root . --require-index
```

把该命令放入仓库自己的 `.git/hooks/pre-commit` 或团队 hook 管理工具。脚本读取 `git diff --cached --name-status -z`，能正确展开 Git rename 记录；它不会自行修改暂存区。

Perforce 和 Plastic SCM 使用统一 UTF-8 TSV 清单入口。由团队现有提交触发器导出 `A/M/D<TAB>PATH`，重命名写为 `R<TAB>OLD<TAB>NEW`，然后运行：

```powershell
python <PLUGIN_ROOT>\tools\usem_precommit.py --project-root . --manifest changed-files.tsv --require-index
```

检查器要求每个 `Content/**/*.uasset` 或 `.umap` 的对应 `.uesem/content|maps/Game/**/*.uesem.json` 同处一个 changelist；非删除资产还会核对 JSON、`packageName` 与源文件 SHA-256。Sidecar 路径由资产路径确定，并只在项目索引中记录。全项目状态校验仍使用 `UERingValidate` Commandlet。
